## Root causes found today

1. **Login/signup 404.** Kong had no `/auth/v1` route; Supabase calls fell
   through to the Next.js catch-all. Fixed in `configmap.yaml` (plus storage
   and realtime, which had the same gap).
2. **Kong never restarted on config change.** No checksum annotation on the pod
   template. Fixed in `deployment.yaml`.
3. **Chat "hang".** Not a hang: the deployed `config.yaml` carried an invalid
   `anthropic_api_key`; `config/loader.py` exported it into the environment;
   the CLI preferred it over the valid `CLAUDE_CODE_OAUTH_TOKEN` and retried
   the 401 for about 180s under a spinner. Fixed operationally by removing the
   key from `inres-secrets`. Code now warns when both credentials are present
   and verifies a configured key at startup (`session/config.py`, wired in
   `lifespan`).
4. **Webhook URLs showed `http://localhost:8080`.** `webhook_api_base_url` was
   unset; the URL is baked into the row at creation. Now documented in
   `cfg.ex.yaml`. Existing rows need the SQL below.
5. **`/webhook/...` unrouted through Kong.** Same class as (1). Fixed.
6. **PagerDuty deliveries dropped at the ALB.** Allowlist lacked their IPs.
   Applied to the live ingress; `inres-values.yaml` in the working tree has it.
7. **`pagey.ping` created blank incidents.** Handler now ignores non
   `incident.*` events (`webhook.go`, tests in `webhook_pagerduty_test.go`).

A wrong turn worth recording: uvloop was suspected and changed, then disproved
by the live result and fully reverted. Every probe that "passed" had bypassed
the app's config loader; the lesson is in issue draft 01.

## Things that bit us, for next time

- `helm upgrade -f inres-values.yaml` without `image.tag` drops to the chart's appVersion (1.11.1) and downgrades every image. The pin in `inres-values.yaml` prevents this.
- Pods cannot reach `inres.metadefender.com`; the ALB allowlist excludes the NAT egress IP. In-cluster probes must use service DNS.
- kubectl exec streams longer than about a minute die (`http2: client connection lost`). Launch with `nohup ... &` and read the log file in a second call.
- A probe of the agent must `import claude_agent_api_v1` to see the environment the app sees; otherwise config.yaml exports are missing and results are misleading.
- `kubectl describe secret` shows key names and sizes without values; use it before reaching for the value.
